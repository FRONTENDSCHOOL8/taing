# 테킷 프론트엔드스쿨 8기 바닐라 프로젝트 - TAING

## 바닐라 프로젝트 4조 - 선영이의 배를탄조

### 팀 구성원

- 팀장: [강선영](https://github.com/ksyee)

- 팀원: [김훈](https://github.com/hoon0817), [문예은](https://github.com/mondimhaus), [박다은](https://github.com/dannxnni)

### 개요

TAING은 OTT서비스인 TVING을 클론코딩한 프로젝트입니다.

### 주요 기능

1. 반응형 디자인
2. 회원가입, 로그인 기능
3. 아이디, 비밀번호 찾기 기능 (본인인증 찾기는 구현안됨)
4. 검색, 최근 검색어 저장 기능
5. 영화 상세 페이지 제공
